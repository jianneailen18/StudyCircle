Project Overview:
concept Proposal:
Audience-classmates (about 3–10 students) reviewing for a quiz or exam together on the same Wi-Fi or LAN.
How Study Circle helps beyond ordinary messaging- two shared tools sit next to the chat. Both are owned by the server, so everybody always sees the same ranking and the same poll result.
**Original feature 1 – Shared Question Queue**
- Any student adds a question and it appears on every screen.
- Classmates upvote it (click again to remove the vote). The server sorts the queue: open questions first, most upvotes on top, oldest first when tied; resolved ones sink to the bottom.
- The asker marks it resolved (anyone may, if the asker has left).

**Original feature 2 – Live Poll**
- Any student starts a poll (question + 2 to 5 options).
- Everyone votes; voting again *changes* your vote. The server counts and pushes *live results* (counts and percentage bars) to every client after each vote.
- One open poll at a time; only the creator can close it (the server closes it automatically if the creator leaves).
**
Original feature 3 – Server annouce and timer tab**
-Server can announce an important announcement for every client.
-Server sets a time duration for announcement. 

**Original feature 4 – server quiz tab**
-creator can ask question and select for an accurate answer 
-server may sets study/response time for every question .
-leaderboard for most accurate answer may seen below for reference of their gained understanding the lesson.

**User Problem:**
In an ordinary group chat, (1) questions get buried under other messages and nobody can tell which ones the group cares about, and (2) group decisions such as "what do we review first?" turn into many replies that someone must count by hand.
